## 🔐 메시지 잠금 및 보안 촬영 자동화

**iOS / iPadOS 27 기준**

메시지 앱을 열었을 때 **메시지 잠금 및 보안 촬영** 단축어가 자동으로 실행되도록 설정하는 방법입니다.

## 📥 단축어 다운로드

자동화를 설정하기 전에 먼저 단축어를 다운로드하세요.

👉 [🔐 메시지 잠금 및 보안 촬영 다운로드](https://www.icloud.com/shortcuts/2dbc7d91053943c3862a59e87a8a410b)

> ⚠️ 자동화를 설정하기 전에 단축어를 먼저 다운로드해야 합니다.

## ⚙️ 자동화 설정 방법

1. **단축어 앱**을 엽니다.
2. **모든 단축어** 화면으로 이동합니다.
3. 오른쪽 위의 **＋** 버튼을 누릅니다.
4. 검색창에서 **자동화**를 검색합니다.
5. **앱**을 선택합니다.
6. **메시지**를 선택합니다.
7. **동작 바로 실행**을 켭니다.
8. **다음**을 누릅니다.
9. **새로운 단축어**를 누릅니다.
10. 동작 검색창에서 **단축어 실행**을 검색합니다.
11. **단축어 실행**을 선택합니다.
12. **메시지 잠금 및 보안 촬영**을 선택합니다.
13. **완료**를 누릅니다.

## 🚀 작동 방식

💬 메시지 앱 열기  
↓  
⚡ 자동화 실행  
↓  
🔐 메시지 잠금 및 보안 촬영 실행  
↓  
📸 설정된 보안 동작 실행

## ✅ 설정 완료!

이제 **메시지 앱을 열 때마다**  
**메시지 잠금 및 보안 촬영** 단축어가 자동으로 실행됩니다.

# 🇺🇸 English

## 🔐 Message Lock & Security Photo Automation

**For iOS / iPadOS 27**

This guide explains how to automatically run **Message Lock & Security Photo** when the Messages app is opened.

## 📥 Download the Shortcut

Download the shortcut before setting up the automation.

👉 [🔐 Download Message Lock & Security Photo](https://www.icloud.com/shortcuts/2dbc7d91053943c3862a59e87a8a410b)

> ⚠️ You must download the shortcut before setting up the automation.

## ⚙️ How to Set Up the Automation

1. Open the **Shortcuts** app.
2. Go to **All Shortcuts**.
3. Tap the **＋** button in the top-right corner.
4. Search for **Automation**.
5. Select **App**.
6. Select **Messages**.
7. Turn on **Run Immediately**.
8. Tap **Next**.
9. Tap **New Blank Automation**.
10. Search for **Run Shortcut**.
11. Select **Run Shortcut**.
12. Select **Message Lock & Security Photo**.
13. Tap **Done**.

## 🚀 How It Works

💬 Open the Messages app  
↓  
⚡ Automation runs  
↓  
🔐 Message Lock & Security Photo runs  
↓  
📸 The configured security action runs

## ✅ Setup Complete!

Now, whenever you open the **Messages** app,  
**Message Lock & Security Photo** will run automatically.

### 📱 Supported Devices

- iPhone
- iPad
- iOS 27
- iPadOS 27

# 🇨🇳 中文

## 🔐 信息锁定与安全拍照自动化

**适用于 iOS / iPadOS 27**

本指南介绍如何在打开“信息”App 时自动运行**信息锁定与安全拍照**快捷指令。

## 📥 下载快捷指令

设置自动化之前，请先下载快捷指令。

👉 [🔐 下载信息锁定与安全拍照](https://www.icloud.com/shortcuts/2dbc7d91053943c3862a59e87a8a410b)

> ⚠️ 设置自动化之前，必须先下载快捷指令。

## ⚙️ 自动化设置方法

1. 打开 **“快捷指令”** App。
2. 进入 **“所有快捷指令”**。
3. 点击右上角的 **＋** 按钮。
4. 在搜索框中搜索 **“自动化”**。
5. 选择 **“App”**。
6. 选择 **“信息”**。
7. 开启 **“立即运行”**。
8. 点击 **“下一步”**。
9. 点击 **“新建空白自动化”**。
10. 在动作搜索框中搜索 **“运行快捷指令”**。
11. 选择 **“运行快捷指令”**。
12. 选择 **“信息锁定与安全拍照”**。
13. 点击 **“完成”**。

## 🚀 工作方式

💬 打开“信息”App  
↓  
⚡ 自动化运行  
↓  
🔐 运行“信息锁定与安全拍照”  
↓  
📸 执行设置的安全操作

## ✅ 设置完成！

现在，每当你打开 **“信息”App** 时，  
**“信息锁定与安全拍照”** 就会自动运行。

### 📱 支持设备

- iPhone
- iPad
- iOS 27
- iPadOS 27

# 🇯🇵 日本語

## 🔐 メッセージロック＆セキュリティ撮影オートメーション

**iOS / iPadOS 27 対応**

「メッセージ」アプリを開いたときに、**メッセージロック＆セキュリティ撮影**ショートカットを自動的に実行する方法です。

## 📥 ショートカットをダウンロード

オートメーションを設定する前に、ショートカットをダウンロードしてください。

👉 [🔐 メッセージロック＆セキュリティ撮影をダウンロード](https://www.icloud.com/shortcuts/2dbc7d91053943c3862a59e87a8a410b)

> ⚠️ オートメーションを設定する前に、ショートカットをダウンロードする必要があります。

## ⚙️ オートメーションの設定方法

1. **「ショートカット」**アプリを開きます。
2. **「すべてのショートカット」**に移動します。
3. 右上の **＋** ボタンをタップします。
4. 検索ボックスで **「オートメーション」**を検索します。
5. **「アプリ」**を選択します。
6. **「メッセージ」**を選択します。
7. **「すぐに実行」**をオンにします。
8. **「次へ」**をタップします。
9. **「新規の空のオートメーション」**をタップします。
10. アクション検索で **「ショートカットを実行」**を検索します。
11. **「ショートカットを実行」**を選択します。
12. **「メッセージロック＆セキュリティ撮影」**を選択します。
13. **「完了」**をタップします。

## 🚀 動作の流れ

💬 「メッセージ」を開く  
↓  
⚡ オートメーションが実行される  
↓  
🔐 「メッセージロック＆セキュリティ撮影」が実行される  
↓  
📸 設定したセキュリティ動作が実行される

## ✅ 設定完了！

これで **「メッセージ」アプリを開くたびに**、  
**「メッセージロック＆セキュリティ撮影」**が自動的に実行されます。

### 📱 対応デバイス

- iPhone
- iPad
- iOS 27
- iPadOS 27
