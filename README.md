## ⚙️ 자동화 설정 방법

1. **단축어 앱**을 엽니다.
2. **자동화** 탭을 누릅니다.
3. 오른쪽 위 **＋** 버튼을 누릅니다.
4. **앱**을 선택합니다.
5. **메시지**를 선택합니다.
6. **동작 바로 실행**을 켭니다.
7. **다음**을 누릅니다.
8. **새로운 단축어**를 누릅니다.
9. **단축어 실행**을 검색합니다.
10. **단축어 실행**을 선택합니다.
11. **메시지 잠금 및 보안 촬영**을 선택합니다.
12. **완료**를 누릅니다.
